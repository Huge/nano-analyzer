Často kladené otázky

Vše o našem modelu účtování kreditu.

Expirují předplacené kredity?

Ne. Kredit zůstává na vašem účtu, dokud jej neproskenujete. Když má tým volnější měsíc s málo PR, kredit nikam nemizí.

Co když sken selže?

Pokud sken narazí na chybu infrastruktury nebo výjimku, z kreditu se neodečte ani cent. Platíte pouze za úspěšné audity.

Můžeme použít vlastní LLM klíče?

Ano. On-premise či vlastní runnery mohou volat vaše vlastní API endpointy (OpenAI, Vertex AI, Ollama, vLLM) s 0% marží na compute.

Jak funguje parametr --max-delay?

Když se blíží nastavený časový limit, skener přestane spouštět nová kola triáže a odešle částečný report bez prodlužování běhu pipeline.
